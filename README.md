# FoxFireFive's Logic Gates
Adds the rest of the logic gates to Logic World.

This adds the NAND, NOR, OR, and XNOR gates to Logic World.
I will keep this updated as long as I live.

These should have the exact same performance as the regular AND and XOR gates.

There are secret settings in `settings_master.jecs` to change the max pin count for the logic gates.

The mod's actual name is `LogicGates`

# Dependencies
- EccsGuiBuilder
- EccsLogicWorldAPI

Source for these mods: https://github.com/Ecconia/Ecconia-LogicWorld-Mods
